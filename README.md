# aathirai-website

Personal website for Dr. Aathirai Balasubramanian — https://aathiraib.com

Plain HTML/CSS, hosted on GitHub Pages (no build step).

- `index.html` — homepage content.
- `cases.html` — case gallery; case text lives in the `CASES` array in the script, images in `assets/cases/<id>-<view>-before|after.jpg`. Eyes are masked on all face photos.
- `css/style.css` — styles.
- Booking: paste the Calendly link into `BOOKING_URL` at the bottom of `index.html` (WhatsApp is used until then).
