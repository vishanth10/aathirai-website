# aathirai-website

Personal website for Dr. Aathirai Balasubramanian — https://aathiraib.com

Plain HTML/CSS, hosted on GitHub Pages (no build step).

- `index.html` — all content. Placeholders are marked `class="placeholder"` and `<!-- TODO -->`.
- `css/style.css` — styles.
- Booking: set `BOOKING_URL` and `WHATSAPP_NUMBER` at the bottom of `index.html`.
- Photo: add `assets/aathirai.jpg` and follow the TODO in the hero section.
